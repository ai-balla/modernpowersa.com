# Modern Power Marine Services website

Arabic and English public website with a PHP/MySQL admin panel, blog and contact inbox.

- Public site: https://modernpowersa.com/ar/ and /en/.
- Website management: https://modernpowersa.com/admin/.
- Baseline templates: generated by `_src/build.py` from bilingual content records.
- Live page edits, articles, public settings and contact requests: stored in MySQL.
- Publishing: `deploy.cmd`, through the saved private FTP pipeline. A GitHub push alone does not publish the site.
- Credentials and server configuration: outside the public website and excluded from Git.

Read `_docs/ADMIN-GUIDE.md`, `_docs/CONTENT-GUIDE.md`, `_docs/DEPLOYMENT.md` and `_docs/FTP-DEPLOYMENT.md`. Maintainers should also read the separately delivered private AGENT.md handbook.
